🎵 Help & Documentation

Need help setting up API keys or configuring services? Our comprehensive guide has you covered!

🎮 Discord Setup

Create a Discord application and get your Client ID for rich presence integration.

Step 1: Create a Discord Application

  1. Go to https://discord.com/developers/applications
  2. Click "New Application"
  3. Give it a name (e.g., "My Roon Rich Presence")
  4. Click "Create"

Step 2: Get Your Client ID

  1. In your new application, you'll see the "Application ID"
  2. Copy this ID - this is your Discord Client ID
  3. Go to the Configuration tab in this app
  4. Paste the ID into the "Discord Client ID" field
  5. Save the configuration
💡 Tip: Your Discord status will appear when music is playing in Roon!

🎵 Roon Configuration

Roon setup is now fully automatic! The app will automatically discover and connect to your Roon Core.

Automatic Setup (Default)

  1. Make sure your Roon Core is running on the same network
  2. Start this application
  3. The app will automatically discover your Roon Core
  4. In Roon, accept the pairing request:
    • Click the gear icon (⚙️) in the top right corner of Roon
    • Select "Settings"
    • Click "Extensions" in the left sidebar
    • Find "Discord Rich Presence" and click "Enable"
  5. The app will automatically detect the currently playing track from any zone

What You'll See

  • Status Page: Shows connection status and currently playing track
  • Now Playing: Displays track info, artist, album, and artwork
  • Automatic Zone Detection: Monitors all zones and shows the currently playing track
✅ That's it! No manual configuration needed. The app automatically handles zone detection and track monitoring.

🎧 Spotify Integration

Optional: Add Spotify links to your Discord status for easy music sharing.

Step 1: Create a Spotify App

  1. Go to https://developer.spotify.com/dashboard
  2. Log in with your Spotify account
  3. Click "Create an App"
  4. Fill in the required information (name and description)
  5. Click "Create"

Step 2: Get Your Credentials

  1. In your new app, copy the "Client ID"
  2. Click "Show Client Secret" and copy the "Client Secret"
  3. Go to the Configuration tab in this app
  4. Enter the Client ID in the "Spotify Client ID" field
  5. Enter the Client Secret in the "Spotify Client Secret" field
💡 Note: Spotify integration adds "Listen on Spotify" links to your Discord status when available.

🖼️ Imgur Setup

Optional: Upload album artwork to enhance your Discord rich presence.

Option 1: Anonymous Mode (Recommended)

  1. Go to https://api.imgur.com/oauth2/addclient
  2. Fill in the application details:
    • Application name: Any name (e.g., "Roon Discord Rich Presence")
    • Authorization type: Select "Anonymous usage without user authorization"
    • Authorization callback URL: Leave blank or use any URL
    • Application website: Optional
    • Email: Your email address
    • Description: Brief description of your app
  3. Submit the form
  4. Copy your Client ID
  5. Go to the Configuration tab in this app
  6. Paste it into the "Imgur Client ID" field

Option 2: OAuth2 Mode (Advanced)

For users who want authenticated uploads linked to their Imgur account:

  1. Go to https://api.imgur.com/oauth2/addclient
  2. Fill in the application details:
    • Application name: Any name
    • Authorization type: Select "OAuth 2 authorization with a callback URL"
    • Authorization callback URL: http://localhost:8080/callback (or your app's callback URL)
    • Application website: Optional
    • Email: Your email address
    • Description: Brief description
  3. Submit the form
  4. Copy both Client ID and Client Secret
  5. Configure in this app:
    • Enter Client ID in the Imgur Client ID field
    • Enter Client Secret in the Imgur Client Secret field (if available)
💡 Anonymous vs OAuth2:
• Anonymous: Simpler setup, uploads are not linked to your account
• OAuth2: Uploads appear in your Imgur account, higher rate limits
✅ Benefit: Album artwork will appear in your Discord rich presence, making it more visually appealing!

🔧 Troubleshooting

Common issues and solutions to get everything working smoothly.

Discord Issues

  • Discord not showing status: Check your Client ID and Discord privacy settings
  • Status shows "Unknown" game: Make sure Discord is running and you're not in invisible mode
  • Rich presence not updating: Try restarting Discord and this app

Roon Connection Issues

  • Can't connect to Roon: Ensure Roon Core is running and accept the pairing request
  • Connection keeps dropping: Check your network connection and firewall settings
  • No track information: Make sure music is playing in Roon and the zone is active

Album Artwork Issues

  • No album artwork: Verify your Imgur Client ID or check internet connection
  • Artwork not updating: Some albums may not have artwork available
  • Upload failures: Check your internet connection and Imgur service status

Spotify Integration Issues

  • Spotify links not working: Double-check both Client ID and Client Secret
  • Track not found on Spotify: Some tracks may not be available due to different metadata
  • Links not appearing: Make sure the track is available on Spotify
💡 Still having issues? Check the Logs tab in the app for detailed error messages that can help identify the problem.
